# Security Policy

## Supported Versions

This project is a learning and demonstration repository.
Security updates are applied to the latest version on the main branch.

## Reporting a Vulnerability

If you discover a security vulnerability:

1. Do not publish exploit details in a public issue.
2. Report the issue privately to the repository maintainer.
3. Include steps to reproduce the vulnerability where possible.
4. Allow time for investigation and remediation before public disclosure.

For private reports, use GitHub's private vulnerability reporting feature if it is enabled for this repository.

## Scope

This project contains demonstration detection rules, incident response runbooks, and security tools.

It is not intended to be used as a production security platform without further testing and review.
